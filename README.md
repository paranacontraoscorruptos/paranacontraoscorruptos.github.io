# Painel dos municípios · Paraná

Site criado pelo **Atlas · Paraná Contra os Corruptos** em 30 de outubro de 2026.

## Abrir

Abra o arquivo `index.html` (dois cliques). Funciona sem internet.

## Publicar no GitHub Pages (grátis)

O mais fácil: na janela "Criar site" do Atlas, use "Colocar o site no ar". Ou, à mão:

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta (Add file → Upload files).
3. Em Settings → Pages, escolha a branch `main` e a pasta `/ (root)`.
4. Em alguns minutos o site aparece em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Arquivos

- `index.html`: a página (com os dados dentro, para abrir sem internet)
- `css/estilo.css`: o visual
- `js/site.js`: tema, idioma, compartilhar, imprimir, baixar os dados e os gráficos
- `dados/`: os dados do site em JSON
- `fonts/`: fonte Space Grotesk (licença OFL)

Dados: boletins de urna das eleições de 2026 publicados pelo TSE. Análise independente · não é site oficial do TSE.
